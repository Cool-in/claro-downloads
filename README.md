# Claro downloads

Official desktop downloads and offline translation model assets for Claro.

The application source is maintained in a separate private repository. This repository contains distribution assets and third-party notices only.

Desktop builds are currently in beta. A successful build does not establish Windows runtime acceptance or distribution signing.

The offline model is Meta M2M100 418M converted to CTranslate2 int8. Its MIT license and provenance accompany the model release. Claro sells the integrated offline feature; the underlying model remains open-source.
